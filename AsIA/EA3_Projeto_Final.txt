3. COMPONENTES DA SOLUÇÃO

-------------------------------------------------------------------------------

a) Agente de IA (n8n - AI Agent): modelo OpenAI Chat, memória por sessão

   (Simple Memory vinculada ao session_id) e ferramenta de busca vetorial

   (Supabase Vector Store + Embeddings OpenAI).

b) Base de Conhecimento (RAG): PDFs de Suporte Básico de Vida armazenados no

   GitHub. Fluxo de ingestão: GitHub -> Code (Converte JSON) -> HTTP Request ->

   Extract from File (PDF) -> Chunk -> Supabase Vector Store (embeddings).

c) Comunicação (Webhook): Webhook POST -> Edit Fields (normaliza user_message

   e session_id) -> AI Agent -> Edit Fields1 (status, session_id, response) ->

   Respond to Webhook. CORS habilitado para consumo pelo navegador.

d) Aplicação Consumidora: página web (HTML, CSS e JavaScript puro) que envia

   as mensagens ao webhook, mantém o session_id da conversa e exibe as

   respostas formatadas em passos numerados.



4. CASOS DE USO CONTEMPLADOS

-------------------------------------------------------------------------------

- Sangramento intenso / hemorragia

- Engasgo (obstrução de vias aéreas)

- Desmaio / perda de consciência

- Queimaduras

- Parada cardiorrespiratória e RCP

- Dúvidas gerais de primeiros socorros com continuidade de conversa (memória)

Todos os casos possuem atalho na interface e orientação para acionar 192 (SAMU)

ou 193 (Bombeiros).



5. ESPECIFICAÇÃO DA ROTA (CONTRATO)

-------------------------------------------------------------------------------

Método: POST | Content-Type: application/json

Endpoint: https://n8n.incluc0de.com.br/webhook/e016cd76-6d17-42e2-856b-e54911d36482



Entrada:

- user_message (String, Obrigatório): relato da emergência ou dúvida.

- session_id (String, Opcional): identificador da sessão para o histórico.



Saída:

- status (String): "success" ou "error".

- session_id (String): identificador mantido/gerado para a conversa.

- response (String): orientações em passos numerados geradas pelo agente.



Exemplo de requisição:

{

  "user_message": "Uma pessoa desmaiou, o que faço?",

  "session_id": "sessao-1793137612005"

}



Exemplo de resposta (HTTP 200):

{

  "status": "success",

  "session_id": "sessao-1793137612005",

  "response": "1. Verifique a segurança do local...\n2. Verifique se a pessoa está consciente...\n...\nSou uma inteligência artificial de suporte e estas diretrizes não substituem o atendimento médico profissional."

}
